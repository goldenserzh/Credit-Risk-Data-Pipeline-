# Credit Risk Data Pipeline & EDA 💳

Автоматизированный конвейер (ETL) для обработки данных по кредитным рискам. Проект включает в себя оркестрацию в Airflow, предобработку сырых данных из PostgreSQL и модуль для визуального анализа (EDA).

## 📌 Архитектура проекта

Проект автоматизирует путь данных от сырых таблиц в БД до готовых витрин для машинного обучения:

1.  **Extract**: Загрузка данных из PostgreSQL (таблицы `application`, `bureau`).
2.  **Transform**: Очистка, заполнение пропусков и генерация бизнес-метрика (DTI, уровень долга).
3.  **Load**: Сохранение обработанных данных обратно в БД в схему `dwh`.
4.  **EDA**: Анализ распределений и факторов дефолта.



---

## 📂 Структура проекта

* **`dag_task.py`** — Определение Airflow DAG. Содержит задачи по загрузке и обработке.
* **`src/preprocessing.py`** — Ядро обработки данных: функции очистки и генерации признаков.
* **`src/analysis.py`** — Инструменты для визуализации (гистограммы, боксплоты, анализ кредитной истории).

## 🚀 Основные возможности

### 1. Интеллектуальная обработка данных
Программа автоматически определяет тип признаков и применяет соответствующие методы:
* **Числовые признаки**: Заполнение пропусков средним значением.
* **Категориальные признаки**: Заполнение модой и приведение к строковому типу.

### 2. Feature Engineering
В пайплайн встроены расчеты ключевых финансовых показателей:
* **Total Debt**: Агрегация всех текущих задолженностей из бюро.
* **DTI (Debt-to-Income Ratio)**: Отношение суммы кредитного аннуитета и долга к общему доходу.
* **Family Classification**: Категоризация семей (бездетные, обычные, большие, огромные) для анализа социального профиля заемщика.

### 3. Разведочный анализ (EDA)
Модуль визуализации позволяет быстро оценить:
* Распределение возраста заемщиков.
* Зависимость дефолта от уровня дохода.
* Влияние количества детей на платежеспособность.


## ⚙️ Настройка и использование

### Настройка Airflow
1.  Установите соединение с БД в интерфейсе Airflow (`Admin -> Connections`). Используйте `conn_id: postgres_default`.
2.  Либо задайте переменные окружения: `HOST`, `PG_LOGIN`, `PG_PASS`, `PG_DB`.

### Запуск пайплайна
Скопируйте файлы в вашу директорию `DAGS_FOLDER`. Airflow автоматически подхватит DAG `task_1`. Пайплайн настроен на ежедневный запуск (`@daily`).
